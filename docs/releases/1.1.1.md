# MicLine 1.1.1

## Lower background CPU usage

- Keep the live menu-bar meter with much less rendering work. MicLine now reuses its meter images and redraws only when a visible bar changes.
- Closed, hidden and fully covered meter windows stop receiving level updates and show current levels when reopened.
- Reduce background polling while processing is stopped, while retaining device discovery and recovery.

## Settings opens in front

Settings now comes to the foreground when opened from the menu bar or with Command-comma, including when the Dock icon is hidden.

Audio routing, gain and effect processing are unchanged. Third-party Audio Units retain their own CPU and memory costs.
