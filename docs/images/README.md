# Product screenshots

`micline-processing.jpg` and `guided-setup.jpg` were captured from the running
native app on macOS 27 on 24 September 2026, using the 1.0.0 UI source. The local
build was development-signed. They are unaltered app-window captures, not mockups.

The processing example uses fifine input 1 → BlackHole 16ch outputs 1–2 with the
Apple AUDynamicsProcessor. Device names and gain are examples, not recommended
settings. The temporary effect was removed afterward; no microphone PCM was saved.
The setup image shows its bundled instructional recording playing inside the app.

The official Ko-fi asset's source and permission links remain beside its use in
the root README. Original MicLine captures use the repository license.
