# MicLine design provenance

Production UI uses native SwiftUI/AppKit controls and system typography. No
Apple design kit or community template is bundled with MicLine.

Earlier SVG/PNG/FIG drafts have been removed from the current tree because their
provenance was not independently established. Historical drafts were removed as
part of the scoped pre-public cleanup. This does not claim platform readiness.

New design sources may be committed only after confirming original project
geometry, documenting any third-party permissions, and replacing machine-specific
device/plugin details with explicitly synthetic examples. Mockups are design
references, not runtime verification. Actual UI must be tested independently.

The original application icon has separate provenance in [ICON.md](ICON.md).
The official Ko-fi button is unchanged; its source and permission links are in
the root README. Neither grants rights to third-party trademarks generally.
